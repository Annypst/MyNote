### 🛠️ 我们的实战项目：**面向 AI 算力调配的“学生 & 算力资源管理系统”**

传统的学生管理系统只是简单的“增删改查”姓名和学号，写起来有点枯燥。

我们把它的背景升级一下：

> 假设太原理工大学的软件工程实验室里有一批**显卡（GPU）算力资源**（比如 H100、RTX 4090）。因为 GPU 很贵，学生们必须登记申请使用。
>
> 你需要用 C++ 写一个系统，管理**学生信息**和**显卡资源分配**。

#### 🚀 这个项目会强迫你交出以下 C++ 核心答卷：

1. **各种函数的使用**：把代码规范地拆分为 `.h` 头文件和 `.cpp` 源文件，搞懂 C++ 独有的编译链接机制。
2. **指针与引用**：学生去申请 GPU 时，不能把整张显卡的对象“复制（拷贝）”一份给他，你必须传**指针**或者**引用**，让学生直接指向那张物理显卡。
3. **动态内存分配（堆区）**：学生和显卡的数据不能写死，必须支持在程序运行期间动态 `new` 出来，并在退出或删除时手动 `delete` 干净，绝对不能内存泄漏。
4. **类与面向对象**：设计 `Student` 类和 `GPU` 类，并实现继承（比如普通本科生和研究生申请显卡的权限、时长不同）。
5. **模板（Template）的实战**：亲手写一个**通用的动态数组模板类（自己实现一个极简版的 `std::vector`）**，用它来同时管理学生列表和 GPU 列表，彻底搞懂模板的底层原理。
6. **文件 I/O 操作**：把学生和显卡的数据实时保存到本地的 `.txt` 或 `.csv` 文件中，下次启动自动读取。
