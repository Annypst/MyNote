# C++ 指针与引用

2026/7/15

### 一、 指针 (Pointer) —— 内存的“门牌号”

- **本质**：指针是一个变量，它占有内存空间，但它里面存的不是普通数值，而是**另一块内存空间的物理地址（门牌号）**。
- **两大核心操作符**：
  - `&`（取地址符）：获取一个普通变量的内存地址。例如 `p = &a;`
  - `*`（解引用符）：顺着指针存的地址，强行摸过去读写那块内存的数据。例如 `*p = 20;`
- **空指针 `nullptr`**：现代 C++ 中专门用来表示“该指针什么都不指向”的关键字。声明指针时若不立即初始化，应赋值为 `nullptr`，避免野指针。
- **`const` 与指针的结合**（看 `const` 在 `*` 的哪边）：
  - `const int* p`（常量指针）：`const` 在 `*` 左边，限制**不能通过该指针修改指向的数据**，但指针本身的指向可以改。
  - `int* const p`（指针常量）：`const` 在 `*` 右边，限制**指针本身的指向不能改**，一辈子只能指向初始化时的那个变量，但数据可以改。

### 二、 引用 (Reference) —— 变量的“外号”

- **本质**：引用是给一个已存在的变量起一个**别名（外号）**。它在底层由编译器自动翻译成**指针常量**（`Type* const`）来实现，属于“全自动挡的指针”。
- **核心语法**：`int& b = a;` （`b` 成为 `a` 的引用，修改 `b` 就是修改 `a`）。
- **三大铁律**（与指针的本质区别）：
  1. **必须初始化**：有本名才能有外号，不允许 `int& b;` 这样单独存在。
  2. **不能变心**：一旦初始化绑定了某个变量，就一辈子绑定它，无法再改去引用别的变量。
  3. **不能为空**：不存在空引用，引用必须绑定一块合法的内存。

### 三、 内存生存守则与致命雷区（大厂面试高频、新手必踩）

- **值传递 vs 引用/指针传递**：
  - **值传递**会发生内存拷贝，效率低，且函数内部无法修改外部变量的值。
  - **引用传递**（例如 `void swap(int& x, int& y)`）和**指针传递**直接传递地址，零拷贝，效率极高，能直接修改外部变量。
- **【致命雷区】返回局部变量的指针/引用**：
  - 栈区局部变量随着函数大括号结束而被系统瞬间回收。
  - 如果函数返回了局部变量的指针或引用，外部去访问它，就会导致**非法内存访问**。
  - **后果**：在严格的操作系统（如 Windows）上，直接表现为 **程序崩溃闪退**。
  - **解决方案**：如果数据生命周期需要跨越函数，必须使用 `new` 关键字将其开辟在**堆区**。

### Example Programs

1.This may cause a crash.

```cpp
#include <iostream>

// 【作死函数】：返回了一个栈区局部变量的引用
int& testRef() {
    int temp = 100; // temp 是栈区的局部变量，函数结束立刻死亡
    return temp;    // 警告！返回了局部变量的引用
}

int main() {
    // 拿一个引用去接这个返回值
    int& arr = testRef();

    std::cout << "第一次打印: " << arr << std::endl;
    std::cout << "第二次打印: " << arr << std::endl;

    return 0;
}
```

2.Value copy and reference copy.

值传递只是拷贝了一份给函数，因此这是安全的。

```cpp
#include <iostream>

// 姿势 1：值传递（普通的 Java 传参思维）
void swapByValue(int x, int y) {
    int temp = x;
    x = y;
    y = temp;
}

// 姿势 2：指针传递（C 语言的硬核经典写法）
void swapByPointer(int* x, int* y) {
    int temp = *x; // 解引用，拿到 x 指向的房子的数值
    *x = *y;       // 把 y 房子的数值塞进 x 房子里
    *y = temp;     // 把 temp 塞进 y 房子里
}

// 姿势 3：引用传递（C++ 独有的优雅写法）
void swapByRef(int& x, int& y) { // x 和 y 直接作为传入变量的“外号”
    int temp = x;
    x = y;
    y = temp;
}

int main() {
    int a = 10;
    int b = 20;

    // 测试 1：值传递
    swapByValue(a, b);
    std::cout << "值传递后 - a: " << a << ", b: " << b << " (应该还是 10, 20)" << std::endl;

    // 测试 2：指针传递（需要手动用 & 传入地址）
    swapByPointer(&a, &b);
    std::cout << "指针传递后 - a: " << a << ", b: " << b << " (应该成功交换为 20, 10)" << std::endl;

    // 重置一下数值
    a = 10; b = 20;

    // 测试 3：引用传递（直接传变量名，极其自然）
    swapByRef(a, b);
    std::cout << "引用传递后 - a: " << a << ", b: " << b << " (应该成功交换为 20, 10)" << std::endl;

    return 0;
}
```
