# 做题方法

## 大作文

### discuss

1. 事实背景+引出争论+套句
2. 论证A观点合理性
3. 论证B观点合理性
4. 我认为（符合实际情况）

### advantages  and disadvantages

优大于缺、缺大于优

1. 改题+表明观点
2. 不否认......
3. 但是......
4. 总结，弱化优点/缺点

### report

1. 改题+过渡（我认为原因有很多方案也有很多）
2. 原因1、2
3. 方案1、2
4. 总结，重复上面的

### influence/development

积极、消极、积极+消极

1. 改题+表明观点
2. 积极或消极影响论据
3. 积极或消极影响论据
4. 总结

### to what extent do you agree or disagree?

1. 改题+表明观点
2. 理由
3. 理由
4. 总结+重申
