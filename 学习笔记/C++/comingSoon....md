类型安全、内存溢出、强弱类型、左值和右值、下划线开始的变量等

## 🧭 物理拆解：这几个词到底在装什么？

### 1. 友元（Friend）—— 给特定朋友开后门

- **物理本质**：C++ 规定类的 `private`（私有）成员别人不能碰。但有时，某个外部函数或另一个类需要频繁读写它。如果为了它专门写一堆 `get/set` 函数，性能和代码都会打折扣。
- **解决**：在类内部写一行 `friend class/function`。相当于在自家的防火墙上**为特定朋友IP开了一个免密通道**。
- **大作业场景**：我们重载输出流（直接打印学生信息）时，必须用友元，否则 `std::cout` 没权限读取学生类内部的私有属性。

### 2. 纯虚函数（Pure Virtual Function）与抽象类 —— C++ 的“接口（Interface）”

- **物理本质**：在多态中，有些父类只是一个“概念”，它自己根本不应该有具体的物理实现。

  - 例如：定义一个父类 `GPU`，世界上根本不存在一张卡叫“通用GPU”，只存在具体的 `H100` 或 `A100`。

- **语法**：在虚函数后面写 `= 0`。

  C++

  ```
  virtual void runTask() = 0; // 纯虚函数
  ```

- **效果**：一旦含有纯虚函数，这个类就变成了**抽象类**，编译器在编译期**绝对不允许你直接 `new GPU();`**（防止概念实体化崩溃）。它逼迫你必须去写子类并重写这个方法，这就是 **Java 的 Interface 机制**在 C++ 中的对标。

### 3. 文件流（File Stream）—— 数据的“物理搬运工”

- **物理本质**：程序关闭后，内存里的学生数据就消失了。我们必须用文件流（`std::ofstream` / `std::ifstream`）把内存中的字节数据，通过操作系统物理写入到硬盘的 `.txt` 或 `.dat` 文件里，实现**数据持久化**。
- **大作业场景**：大作业中我们必写这个模块，用来保存和读取学生列表。

### 4. 流输出重载（`operator<<`）—— 优雅地打印自定义对象

- 我们刚刚在 `Dummy` 比大小的实验里其实已经悄悄用过它了！
- 如果不写它，你打印学生只能写 `std::cout << s.name << s.id;`；重载之后，你可以像打印普通整数一样，直接写 `std::cout << student;`。

### 5. 谓词（Predicate）与 仿函数（Functor）—— “假装是函数的对象”

- **仿函数**：在类里重载了小括号 `operator()`。这样，你创建了这个类的对象后，居然可以像调用函数一样用它！

  C++

  ```
  class MyAdder {
  public:
      int operator()(int a, int b) { return a + b; }
  };
  MyAdder add; 
  int sum = add(1, 2); // 对象居然像函数一样被调用了！
  ```

- **谓词**：返回值是 `bool` 的仿函数。

- **现代学术真相**：黑马教程录制时间较早。在 C++11 之后，**Lambda 表达式（就是我们刚刚写的 `[](int a, int b) { return a > b; }`）已经在 95% 的场景下彻底淘汰了繁琐的仿函数和谓词**。Lambda 底层就是编译器帮你自动生成的仿函数，所以我们直接用 Lambda，写起来爽快十倍！
