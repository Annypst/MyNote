# 📘 数据库系统概论（第六版）期末复习笔记 —— 第二章 关系数据库



## 📐 一、 关系代数（大题必考点）

关系代数是以集合为基础的抽象查询语言。大题解题核心在于：**“横选行，纵投列，跨表连，全用除”**。

### 1. 单表基本算子 🔍

- **选择（Selection）`σ`**：**横向筛选行**。
  - *公式*：$\sigma_{条件}(R)$
  - *示例*：选出计算机系学生 ➡️ $\sigma_{Sdept = 'CS'}(Student)$
- **投影（Projection）`π`**：**纵向筛选列**（自动去重）。
  - *公式*：$\pi_{属性列}(R)$
  - *示例*：查询所有学生姓名和年龄 ➡️ $\pi_{Sname, Sage}(Student)$
- **优化金律（选择下推）**：在组合查询时，**先选择（过滤行）再连接（跨表拼）**。这样可以极大地瘦身中间表，提高效率。
  - *满分表达式示例*：$\pi_{Sname}(\sigma_{Sdept = 'CS'}(Student) \bowtie \sigma_{Cno = 'C02'}(SC))$

### 2. 跨表连接算子 🔗

- **等值连接（$\bowtie_{R.A = S.B}$）**：把两张表里指定列中值相等的行拼起来，保留所有列（相同的列会出现两次）。
- **自然连接（$\bowtie$）**：特殊的等值连接。**自动寻找同名列**进行匹配，并且在结果中**自动去掉重复的列**。

### 3. 终极算子：除法（Division）`÷` 🏎️

- **适用场景**：题目中出现“全部”**、**“所有”**、**“每一门”等绝对化字眼。

- **学术铁律**：结果保留的列 = 被除数属性列 - 除数属性列。

- *经典除法公式*（查询选了所有课的学生学号）：

  $$\pi_{Sno, Cno}(SC) \div \pi_{Cno}(Course)$$

  - *核心逻辑*：被除数必须刚好投影为 `[学号, 课程号]`，除数投影为 `[课程号]`，相除后将共同的“课程号”消掉，只留下满足全部条件的“学号”。

## 🛡️ 二、 关系的三类完整性约束

完整性约束是确保数据库数据“正确、有效、相容”的铁律。

| **完整性分类**                                 | **核心控制对象 🎯**     | **考试认定标准 📝**                                           |
| ---------------------------------------------- | ---------------------- | ------------------------------------------------------------ |
| **1. 实体完整性** (Entity Integrity)           | **主键** (Primary Key) | **铁律**：主键（包括组合键中的每一个核心属性）**绝对不能为空（NOT NULL），且必须唯一**。用于唯一标识一个实体。 |
| **2. 参照完整性** (Referential Integrity)      | **外键** (Foreign Key) | **铁律**：外键里填写的每一个值，**必须在主表的主键里真实存在**，或者直接留空（`NULL`）。用于维持表与表之间的显式头尾连接。 |
| **3. 用户定义完整性** (User-defined Integrity) | **业务自定义约束**     | **铁律**：根据现实世界具体业务定的规则。利用 `NOT NULL`、`UNIQUE`、`CHECK` 等实现（如：成绩必须 $\ge 0$ 且 $\le 100$）。 |
