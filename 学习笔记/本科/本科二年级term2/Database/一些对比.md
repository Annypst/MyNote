| **设计阶段**    | **核心任务（在干嘛）**                                       | **考场标志性核心产物（看词秒选）**         |
| --------------- | ------------------------------------------------------------ | ------------------------------------------ |
| **1. 需求分析** | 调查用户要什么数据、怎么用。                                 | **数据流图（DFD）**、数据字典（DDL）       |
| **2. 概念设计** | 纯粹在逻辑上建模，**完全不考虑计算机和具体数据库管理系统**。 | **E-R图（实体-联系图）**                   |
| **3. 逻辑设计** | 把 E-R 图翻译成计算机能懂的**表格结构**，并进行规范化。      | **关系模式（一张张的二维表定义）**、外模式 |
| **4. 物理设计** | 确定表怎么存在硬盘上、**建什么索引**、怎么调优性能。         | 存储结构、**索引（Index）**、存取路径      |

| **模式名称** | **描述的特征维度**                             | **物理对应实体（考场举例）**                | **数量限制** |
| ------------ | ---------------------------------------------- | ------------------------------------------- | ------------ |
| **外模式**   | **局部逻辑特征**（用户看到的局部视图）         | 视图 (View)、或者是应用代码里的查询定义     | 多个         |
| **模式**     | **全局逻辑特征**（所有数据的逻辑总貌）         | 基本表 (Base Table)、DDL 建表语句定义的结构 | **只有一个** |
| **内模式**   | **物理存储特征**（数据在磁盘上的真实物理表示） | 磁盘文件、B+树索引物理文件、存储参数        | **只有一个** |

| **特征维度**     | **自主存取控制 (DAC)**                     | **强制存取控制 (MAC)**                         |
| ---------------- | ------------------------------------------ | ---------------------------------------------- |
| **权力在谁手**   | **数据创建者/拥有者**（用户说了算）        | **系统安全管理员/DBMS底层**（系统说了算）      |
| **安全性级别**   | 较低（容易受到“木马”伪装扩大权限拷贝泄密） | 极高（军事级，木马也无法突破系统级的标签限制） |
| **SQL 表现形式** | 显式的 **`GRANT` / `REVOKE`** 语句         | 隐式的**行级/列级安全策略、密级标签函数**      |
| **控制粒度**     | 通常到**表级、属性列级**                   | 可以精确到**单个元组（数据行级）**的密级       |

| **封锁协议级别** | **写锁(X锁)何时放** | **读锁(S锁)何时放** | **解决的并发冲突**                       |
| ---------------- | ------------------- | ------------------- | ---------------------------------------- |
| **一级协议**     | 事务结束            | **不加锁**          | 解决：丢失修改                           |
| **二级协议**     | 事务结束            | **读完即放**        | 解决：丢失修改、**读脏数据**             |
| **三级协议**     | 事务结束            | **事务结束**        | 解决：丢失修改、读脏数据、**不可重复读** |

| **连接类型**              | **列名（属性名）要求** | **底层硬性前提**             | **最终属性个数（列数）**                           |
| ------------------------- | ---------------------- | ---------------------------- | -------------------------------------------------- |
| **等值连接**              | **完全可以不同**       | 属性的**域（类型）**相容     | $R$ 的列数 $+$ $S$ 的列数（保留重复列）            |
| **自然连接（$\bowtie$）** | **必须有同名列**       | 存在**同名且同域**的公共属性 | $R$ 的列数 $+$ $S$ 的列数 $-$ 公共列数（自动去重） |
