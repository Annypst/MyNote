### 📘 JSP 零基础起步

#### 1. 什么是 JSP？

- 🏷️ **全称**：JavaServer Pages（Java 服务器页面）。
- 🧱 **表面上看**：它是一个普通的网页，里面写满了 HTML 标签。
- ⚙️ **本质上看**：**JSP 本质上就是一个 Servlet**！
- 🔄 **工作原理**：
  1. 当浏览器**第一次**请求一个 `index.jsp` 页面时，Tomcat 会在后台悄悄地把这个 JSP 文件**翻译**成一个 `.java` 源文件（这个类继承了继承自内置的 Servlet 类）。
  2. Tomcat 再把这个 `.java` 文件**编译**成 `.class` 字节码文件去执行。
  3. 所以，JSP 只是披着 HTML 外衣的 Servlet。

### 📘 JSP 脚本语法

为了避免以后写错，我们把 JSP 页面中最常用的三种**脚本元素**（课本 6.2.2 节）记录下来。

| **语法格式**  | **官方名称**                | **作用与特点**                                               | **核心示例**                  |
| ------------- | --------------------------- | ------------------------------------------------------------ | ----------------------------- |
| **`<%   %>`** | **脚本片段 (Scriptlet)**    | 编写普通的 Java 核心代码（方法体内的代码）。                 | `<% int age = 18; %>`         |
| **`<%=  %>`** | **JSP 表达式 (Expression)** | 专门用于**向网页输出**变量的值或表达式结果。**末尾绝对不能加分号 `;`**。 | `当前年龄：<%= age %>`        |
| **`<%!  %>`** | **JSP 声明 (Declaration)**  | 用于声明 JSP 转译后的类成员变量或成员方法。                  | `<%! public void init(){} %>` |

### 📘 JSP 九大隐式对象

根据课本 6.5 节的规划，JSP 一共为我们准备了 **9 个** 这样的内置对象。在期末大题手写 JSP 页面时，你随时可以直接调它们。我们先来看最核心的 5 个：

| **对象名**          | **对应的 Java 类/接口** | **核心作用**                           |
| ------------------- | ----------------------- | -------------------------------------- |
| **`request`** 📥     | `HttpServletRequest`    | 获取客户端浏览器提交的数据和参数。     |
| **`response`** 📤    | `HttpServletResponse`   | 控制服务器对浏览器的响应（如重定向）。 |
| **`session`** 📦     | `HttpSession`           | 保存用户的会话状态（如登录信息）。     |
| **`application`** 🌐 | `ServletContext`        | 整个 Web 应用共享的数据（全局范围）。  |
| **`out`** 🖨️         | `JspWriter`             | 专门用于向网页输出文本内容的字符流。   |
