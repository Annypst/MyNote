> **【判断题 4】监听器（Listener）可以监听 ServletContext 对象的创建与销毁。 ( `✓` )** *你的答案：`✓` （完全正确！）*

### ⚡ 为什么是对的？底层学术机制大起底：

在 Java Web 中，**监听器（Listener）** 就像是服务器里安插的“监控摄像头”。它的核心任务就是盯着三大域对象（`request`、`session`、`application/ServletContext`）的一举一动。

针对 `ServletContext`（代表整个 Web 应用的全局大总管），Java 官方专门提供了一个极其重要的接口：**`ServletContextListener`**。

- **监听创建（出生）**：当 Tomcat 服务器启动，或者你的项目刚被部署上去的那一瞬间，`ServletContext` 对象被创建。此时，监听器内部的 `contextInitialized()` 方法会**立刻自动触发**。
  - *实战用途*：程序员经常在这个方法里写代码来“加载全局配置文件”**或者**“初始化数据库连接池”，让项目一启动就准备好弹药。
- **监听销毁（死亡）**：当 Tomcat 服务器正常关闭，或者你的项目被卸载时，`ServletContext` 面临死亡。此时，监听器内部的 `contextDestroyed()` 方法会**立刻自动触发**。
  - *实战用途*：在这里写代码来“释放数据库连接”**、**“清理内存”，做到死后不留垃圾。

**考场总结**：监听全局大总管生死的 `ServletContextListener` 是八大监听器中最常考的一个，这道题的陈述极其严谨，必须打勾！
