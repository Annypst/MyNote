> **原题】在 Filter 配置信息中，不属于 `dispatcherTypes` 元素的可选值是（ ）** A. `INCLUDE` B. `FORWARD` **C. `RESPONSE`** (标准答案) D. `REQUEST`

- **你的选择：A**
- **⚡ 像素级底层内幕剖析**： 这道题考查的是“什么动作能触发过滤器？” 在 `web.xml` 或 `@WebFilter` 注解中，`dispatcherTypes` 属性专门用来定义拦截的**调度类型**。 Java Web 官方严格规定了 5 种合法的调度触发类型：
  1. **`REQUEST`**（默认值）：只要是浏览器直接发起的请求（敲地址条、点超链接、表单提交），一律拦截。
  2. **`FORWARD`**：专门拦截在服务器内部通过 `request.getRequestDispatcher().forward()` 转发过来的暗箱操作。
  3. **`INCLUDE`**：专门拦截通过 `include()` 方法包含进来的组件片段。
  4. **`ERROR`**：专门拦截跳转到全局错误页面（如 404/500 页面）的动作。
  5. **`ASYNC`**：拦截异步请求（Servlet 3.0 新特性）。
- **🔥 为什么 C 是死穴？** 过滤器虽然可以同时修改 Request 和 Response，但它的**触发源头永远是“请求的调度方式”**。学术规范中**压根不存在 `RESPONSE` 这种调度类型**，它是出题人为了凑选项凭空捏造出来的虚假词汇！
