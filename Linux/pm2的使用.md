# 使用pm2管理和维护你的服务器进程

我最近自己使用老电脑安装了Linux当作我的服务器，主要用于部署我自己的资源和项目，顺便用于学习服务器和Linux。但是当我运行一个node项目时，过了几个小时这个进程就被杀死了，所以我使用pm2管理进程。

pm2是一个用node.js写的进程管理工具，它可以管理你系统的任何进程，你的网站、Java程序，甚至是我的世界服务器。（我非常喜欢自建服务器玩mc，这样就可以随时随地游玩，不用来回导存档了。）

## 注意事项

1. **所有 PM2 命令必须加 `sudo`**（因为项目需要 root 权限）

2. **启动前必须先进入项目目录**

3. 关闭终端、崩溃、重启服务器 → 都不会停止服务

4. 必须先要安装pm2包  

   ```
   sudo npm install -g pm2
   ```

## 相关命令

- 启动：

```bash
# 第一步：进入项目目录（必须） 
cd 你的项目路径 
# 第二步：PM2 守护启动 
sudo pm2 start npm --name "mysite" -- run dev
```

pm2的命令格式是这样的：

```
sudo pm2 start "你的启动命令" --name "自定义名字" -- 启动参数
```

比如我现在要维护我的mysite进程，当我输入后，终端显示：

```
┌────┬────────────────────┬──────────┬──────┬───────────┬──────────┬──────────┐
│ id │ name               │ mode     │ ↺    │ status    │ cpu      │ memory   │
├────┼────────────────────┼──────────┼──────┼───────────┼──────────┼──────────┤
│ 0  │ mysite             │ fork     │ 0    │ online    │ 0%       │ 73.9mb   │
└────┴────────────────────┴──────────┴──────┴───────────┴──────────┴──────────┘
```

显示online就是正在运行，pm2现在正在托管，↺ 就是重启次数，pm2会在程序崩溃后，一直重启这个进程。

- 其他的命令，对于其他的命令，格式还和上面一样，这些命令写在下面：

  ```bash
  pm2 list                # 查看所有进程
  pm2 logs 名字           # 看日志
  pm2 restart 名字        # 重启
  pm2 stop 名字           # 停止
  pm2 delete 名字         # 删除
  pm2 save                # 保存开机自启
  ```

- 设置开机自启：

  我在宿舍放置这个服务器，但是我们宿舍晚上会断电，所以每天早上要手动按下开机键，那么这时候，上次托管的服务就会清空。假如说我每次开机都需要托管，会很麻烦所以要设置开机自启：

  在上面设置start以后，我们输入：

  ```bash
  pm2 startup
  ```

	这时，pm2会给出一个命令，这是对于每个人的机器的命令，先执行这段命令，然后再输入：

	```
	pm2 save
	```

​	现在，pm2就支持自动运行，非常方便。
