

## 📊 太理五年真题：程序填空核心规律速查表

整张试卷的填空题雷打不动分为 **2 个大题，每题 5 个空，共 10 分** 。

### 🧱 阵地一：JDBC 原生底层操作（稳占 5 分，年年必考）

无论是哪一年的考卷，必定有一道大题是让我们在 JSP 页面或 DAO 层里手工补全原生的 JDBC 访问步骤 。其考点通常在以下 5 个黄金位点上反复横跳：  

1. 

   **加载驱动** ➡️ 必填 **`Class.forName`** 。  

2. 

   **建立连接** ➡️ 必填 **`DriverManager.getConnection`**（注意大写） 。  

3. 

   **获取执行器** ➡️ 普通 SQL 填 `con.createStatement()` ；参数化预编译 SQL 填 **`con.prepareStatement(sql)`** 。  

4. 

   **执行 SQL 语句** ➡️ 查询填 `stat.executeQuery(sql)` ；增删改填 **`preStmt.executeUpdate()`** 。  

5. 

   **结果集指针走位** ➡️ 遍历结果集循环条件，必填 **`rs.next()`** 。  

### 🧱 阵地二：会话跟踪技术（Cookie 或 Session 购物车/登录，稳占 5 分）

另一道大题则由 Cookie 和 Session 轮流坐庄，主要考查它们在 Servlet 中最核心的生命周期管理和口袋读写 。  

- 

  **若考 Cookie 机制（如21年、24年）** ：  

  - 召唤所有 Cookie 数组 ➡️ **`request.getCookies()`** 。  
  - 获取属性值 ➡️ `cookies[i].getValue()` 。  
  - 新建 Cookie 对象 ➡️ **`new Cookie(name, value)`** 。  
  - 控死失效时间 ➡️ `cookie.setMaxAge(秒数)` 。  
  - 吐回给浏览器 ➡️ **`response.addCookie(cookie)`** 。  

- 

  **若考 Session 购物车/登录（如22年、23年、25年）** ：  

  - 获取/创建会话 ➡️ **`request.getSession()`** 。  
  - 读口袋数据 ➡️ `session.getAttribute("键")` （通常还要注意强转类型） 。  
  - 存口袋数据 ➡️ **`session.setAttribute("键", 值)`** 。  
  - 集合基本操作 ➡️ 往购物车 List 集合里加东西，考查 Java 基础的 `cart.add(item)` 。
