## 🍪 1. Cookie 核心常用方法速查



`Cookie` 的本质是**由服务器创建、保存在浏览器端**的键值对文本 。  

> ⚠️ **纸考第一死穴**：Java Web 中，**没有** `request.addCookie()`，也**没有** `response.getCookies()` ！ * 拿 Cookie 是浏览器带过来的，找 **`request`** 拿 ；  
>
> - 发 Cookie 是服务器吐给浏览器的，找 **`response`** 发。

### 🛠️ Cookie 核心 API 列表

| **方法名与参数**                            | **调用者类型**        | **返回值类型**        | **纸考核心作用与学术规范**                                   |
| :------------------------------------------ | --------------------- | --------------------- | ------------------------------------------------------------ |
| **`new Cookie(String name, String value)`** | 构造方法              | `Cookie` 对象         | 实例化一个 Cookie，传入键值对。**注意：一旦创建，Name（键）就不能再修改了。** |
| **`request.getCookies()`**                  | `HttpServletRequest`  | **`Cookie[]`** (数组) | 获取客户端浏览器在请求头中携带的**所有** Cookie 。纸考高频考点：返回值是数组，不是 List 集合 ！ |
| **`response.addCookie(Cookie c)`**          | `HttpServletResponse` | `void`                | 服务器通过响应头，向客户端浏览器**发送/回写**一个 Cookie 对象。 |
| **`cookie.getName()`**                      | `Cookie`              | `String`              | 获取当前 Cookie 的名称（键）。                               |
| **`cookie.getValue()`**                     | `Cookie`              | `String`              | 获取当前 Cookie 的存储值。                                   |
| **`cookie.setMaxAge(int expiry)`**          | `Cookie`              | `void`                | 设置 Cookie 的最大生存时间。**单位：秒**。* `> 0`：持久化在硬盘上。* `< 0`（默认 `-1`）：**会话级 Cookie**，保存在浏览器内存，浏览器一关就死 。* `= 0`：**通知浏览器立刻删除该 Cookie** 。 |

## 🎮 2. HttpSession 核心常用方法速查



`Session` 的本质是**保存在服务器端**的会话域对象，用来跟踪用户的身份状态 。它的底层依靠浏览器端的 `JSESSIONID` 这个 Cookie 来一一对应 。  

### 🛠️ Session 核心 API 列表

| **方法名与参数**                                    | **调用者类型**       | **返回值类型** | **纸考核心作用与学术规范**                                   |
| --------------------------------------------------- | -------------------- | -------------- | ------------------------------------------------------------ |
| **`request.getSession()`**                          | `HttpServletRequest` | `HttpSession`  | 获取当前会话的 Session 对象 。如果服务器内存中没有，则**自动创建一个新的**返回 。等价于 `getSession(true)` 。 |
| **`request.getSession(false)`**                     | `HttpServletRequest` | `HttpSession`  | **21/22/23年连续考的判断题核心！** 如果 Session 存在则返回；**若不存在，直接返回 `null`，绝不创建新的** 。 |
| **`session.setAttribute(String name, Object obj)`** | `HttpSession`        | `void`         | **域对象通用方法**。往 Session 口袋里存入一个键值对。**注意：值可以是任意复杂的 Object（如 List、User 对象）。** |
| **`session.getAttribute(String name)`**             | `HttpSession`        | **`Object`**   | **域对象通用方法**。根据键从 Session 口袋里取值。纸考代码大题、填空题重灾区：取出来的值必须强制类型转换 ！（例如：`(List) session.getAttribute("cart")` ）。 |
| **`session.removeAttribute(String name)`**          | `HttpSession`        | `void`         | **域对象通用方法**。从 Session 域中把这个键值对彻底抹去（比如退出登录时清除用户信息）。 |
| **`session.getId()`**                               | `HttpSession`        | `String`       | 获取该 Session 的唯一标识号（即长长的字符串 `JSESSIONID`）。 |
| **`session.invalidate()`**                          | `HttpSession`        | `void`         | **强制使其销毁/无效化** 。通常用于注销、安全退出账户的场景 。 |

### 📘 终极对比口诀（带进考场）

> **Cookie 在外浏览器，数组存放值唯一。MaxAge 单位是个“秒”，发送接收看清谁。** **Session 在内服务器，强转取值要牢记。getSession(false) 不建新，注销销毁用 invalidate！**
